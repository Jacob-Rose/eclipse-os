DMX SETUP - mythos show (config/mythos-show.json)
================================================

All fixtures on ONE DMX line, one universe, from the FTDI/Enttec USB cable.
Every fixture in 7-channel mode.

SET EACH FIXTURE'S ADDRESS ON ITS DISPLAY TO:

  par_1   ->   1   (uses  1-7)
  par_2   ->   8   (uses  8-14)
  par_3   ->  15   (uses 15-21)
  par_4   ->  22   (uses 22-28)
  par_5   ->  29   (uses 29-35)
  par_6   ->  36   (uses 36-42)
  par_7   ->  43   (uses 43-49)
  par_8   ->  50   (uses 50-56)
  par_9   ->  57   (uses 57-63)
  par_10  ->  64   (uses 64-70)
  uv      ->  71   (uses 71-77)  <- EVERY UV par on 71

Last channel used: 77


CHANNEL LAYOUT (each fixture, 7ch mode)
---------------------------------------

  U'King Par 36:              U'King UV Par 36:
    1  dimmer   (held 255)      1  dimmer   (held 255)
    2  red                      2  UV bank 1
    3  green                    3  UV bank 2
    4  blue                     4  UV bank 3
    5  strobe   (held 0)        5  strobe   (held 0)
    6  mode     (held 0)        6  mode     (held 0 = manual)
    7  speed    (held 0)        7  speed    (held 0)


NOT ON DMX
----------
  obelisk       - its own USB cable (relic_usb), no address to set
  scanner_ring  - preview only
  synesthesia   - OSC to the visualiser


CHECKING
--------
  Patch as the software sees it:
    ./build/eclipse-dmx --config config/mythos-show.json --show-patch

  Walk the rig to find which par is which:
    ./build/eclipse-dmx --config config/mythos-show.json --pattern identify
