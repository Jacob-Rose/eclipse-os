16 patterns, config is mythos-show.json.
each state triggers its synesthesia scene (and media) as well.
optional / additive layers for bpm flashes and uv (or any others) have a gui hookup, easy to customize per usage.

each pattern has a "mode" button instead of low / medium / high intensity. one button, cycles 1 -> 2 -> 3 -> 1.
mode 1 is the pattern as written, 2 and 3 are that pattern's own variations. hitting the cue again is mode 1.
a pattern can have a mode 4 (e-churn and e-nova do: three palettes and a rainbow), the button cycles round however many it has.
four more buttons beside it name a mode outright (1 2 3 4) - the palette buttons. on a three-mode pattern, 4 does what 3 does.
numbers here are the pad numbers on the surface. colours are hue / sat / val unless written as rgb.

the probe: the synesthesia scenes that take the rig's colour (e-churn, e-nova) get the pattern's palette colour A, not a sampled point.
a second colour (colour B) goes to the scene from the cue table, one per palette.

14. clouds

mode 2 - dusk: pink (330) overhead into violet (285 / 0.75 / 0.80), the deck darker (260 / 0.70 / 0.10)
mode 3 - golden hour: orange-yellow (42) overhead into orange (18) at the horizon, the deck warm (25 / 0.70 / 0.14), more glow on the tops

synesthesia - Cloud Ten (CHECK: the scene name and its height / speed / auto_height control names are a guess from the spec; the scene is not in the checkout. fix them in the cue table.)
media - white.mp4. the scene multiplies by its media (col *= _loadMediaAsMask().r), so black.mp4 erased it; white is a mask of one. there is no "no media" message. made at 128x72 - see the readme.
